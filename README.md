Програма для обліку будівельних об'єктів, їх обстежень, дефектів і ремонтних завдань. Для кожного дефекту рахується показник I, а стан дефекту змінюється по черзі: ЗАФІКСОВАНО, ПЕРЕВІРЕНО, РЕМОНТ_ПРИЗНАЧЕНО, ЗАКРИТО. Результати обстежень можна завантажити з CSV-файлу.

Є дві частини: server (сервлети, працюють у Tomcat і зберігають дані в MySQL) і client (вікно на JavaFX).

Що використано: Java 21, Maven, JavaFX, Tomcat 9, MySQL з XAMPP, JUnit 5.

## Як запустити

1. Запустити MySQL у XAMPP. У phpMyAdmin виконати файл database.sql, він створить базу building_defects і додасть приклади записів.
   Логін і пароль до бази написані в DBUtil.java (root і порожній пароль). Якщо у вас інші, треба поміняти там.

2. Зібрати сервер: в папці server виконати mvn clean package.
   Файл server/target/building-defects.war скопіювати в папку webapps у Tomcat 9 і запустити bin/startup.bat.
   JAVA_HOME має бути на JDK 21.
   Перевірити можна в браузері: http://localhost:8080/building-defects/objects

3. Запустити клієнт: в папці client виконати mvn javafx:run

Якщо mvn не запускається в терміналі, те саме можна зробити через панель Maven в IntelliJ IDEA.

## Імпорт CSV

Файл має бути в UTF-8, поля через ;, перший рядок такий:

```
object_id;inspection_date;inspector;condition_category;notes
```

Дата пишеться як 2026-10-20, категорія від 1 до 4, примітка може бути порожня, об'єкт з таким номером має бути в базі.

Якщо перший рядок неправильний, імпорт не починається. Якщо в рядку помилка формату (не 5 полів, не число, не та дата), цей рядок пропускається і пишеться в журнал. Якщо сервер не прийняв запис або не відповідає, імпорт зупиняється, а те що вже додалось залишається.

Приклади лежать в client/sample-data: inspections.csv (10 нормальних рядків) і inspections_errors.csv (з помилками).
